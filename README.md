# Tork AI Visualizer & Fitting (Manager-Only Mode)

Интеллектуальный Telegram-бот и инструмент виртуальной примерки настенного оборудования **Tork (Essity)** для официальных дистрибьюторов в Республике Казахстан.

Инструмент работает в **закрытом режиме для менеджеров (Manager-Only Mode)**: доступ предоставляется только авторизованным сотрудникам по их Telegram ID. Менеджер выбирает любой диспенсер из официального каталога (165 товаров), присылает фотографию стены/санузла клиента и за секунды получает реалистичный фотомонтаж с точным соблюдением масштаба, цвета и теней помещения через Google Gemini.

---

## 🚀 Основные возможности

1. **Контроль доступа (Whitelist)**:
   - Доступ ограничен списком разрешенных Telegram ID (`ALLOWED_TELEGRAM_IDS`).
   - Попытки доступа посторонних пользователей вежливо отклоняются с отображением их ID для передачи администратору.

2. **Каталог 165 товаров Tork (Vue.js Mini App)**:
   - Включает 83 настенных диспенсера (H1 Matic, S4, T8 SmartOne и др.) и 82 вида совместимых расходных материалов.
   - 4 функциональные зоны: *Мытье рук*, *Туалетная зона*, *Корзины и аксессуары*, *Протирочные материалы*.
   - Мгновенный поиск по артикулу (например, `551000`), названию или коду системы (`H1`, `S4`, `T8`).
   - Фильтры по цветам (белый, черный, нержавеющая сталь) и габаритам.
   - Кнопка **«✨ Примерить диспенсер»** в один клик передает артикул в чат.

3. **AI-монтаж высокого разрешения (Google Gemini)**:
   - Передача в нейросеть двух изображений: фото объекта клиента + студийный прозрачный PNG выбранного диспенсера.
   - Автоматический расчет масштаба по реальным физическим габаритам (Ш × В × Г см) из базы данных.
   - Сохранение естественного освещения и контактных теней на плитке.

4. **Полная редукция клиентских барьеров**:
   - Отключены дневные лимиты (менеджер может делать неограниченное число примерок).
   - Убран клиентский опрос онбординга (HoReCa, Офис и т.д.).
   - Убраны лишние уведомления в общие группы.

## ⚙️ Быстрый старт

### 1. Настройка окружения
Создайте файл `.env` на основе примера:
```powershell
cp .env.example .env
```
Заполните обязательные переменные:
- `TELEGRAM_BOT_TOKEN`: токен вашего бота от `@BotFather`.
- `ALLOWED_TELEGRAM_IDS`: список Telegram ID менеджеров через запятую (например, `123456789,987654321`).
- `VLM_API_KEY`: API ключ Google Gemini.
- `IMAGE_EDIT_MODEL`: `gemini-3.1-flash-image`.

### 2. Запуск контейнеров
```powershell
docker compose up -d
```
Docker запустит:
- **PostgreSQL 16** (порт 5432) с развернутой базой и каталогом 165 SKU.
- **n8n** (порт 5679:5678) — движок оркестрации сценариев бота.
- **CDN / NGINX** (порт 8088) — раздача Mini App (`/app/index.html`) и изображений (`/images/*.png`).

### 3. Настройка кнопки меню в Telegram
Установите удобную кнопку вызова каталога рядом с полем ввода сообщений:
```powershell
python scripts/set_menu_button.py
```

### 4. Импорт сценария в n8n
1. Перейдите в браузере по адресу `http://localhost:5679` (или `http://localhost:5678`).
2. В разделе **Workflows** нажмите **Import from File** и выберите:
   `workflows/tork_bot_workflow.json`
3. Переведите переключатель в положение **Active**.
